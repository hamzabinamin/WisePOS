# Android WisePOS E Payment Application

An Android application developed in **Java** to integrate with the **Stripe WisePOS E** payment terminal for in-person card payments.

The project focused on integrating a physical payment terminal with an Android application and handling the communication and payment flow between the application and the WisePOS E device.

## Features

* Android application developed in Java
* Stripe WisePOS E terminal integration
* In-person card payment workflow
* Communication between the Android application and payment terminal
* Payment status and transaction handling

## Technologies

* **Java**
* **Android SDK**
* **Stripe**
* **WisePOS E**

## Project Overview

The project provided practical experience integrating third-party payment hardware with a mobile application. It involved working with Android application development, payment APIs/SDKs, device communication, and handling asynchronous payment workflows.

## Repository

This repository contains the Android application source code and supporting files for the WisePOS E integration.
